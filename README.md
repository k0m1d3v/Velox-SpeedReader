# Velox-SpeedReader

Velox is a web-based reader for PDF and EPUB files built for speed reading (RSVP – Rapid Serial Visual Presentation): text is shown one word at a time at a fixed point on the screen, with the pivot letter highlighted, so your eyes never have to move to follow lines.

Text extraction happens entirely in the browser (pdf.js for PDFs, JSZip for EPUBs) — nothing is uploaded to a server
Adjustable reading speed (100–900 wpm) with automatic pauses on punctuation
Customizable font, text size, and number of words per flash
No backend dependency: a single HTML file, works offline once downloaded
